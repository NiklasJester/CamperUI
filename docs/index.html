🚐 CamperUI Flasher • ESP32-S3

Display Erstinbetriebnahme

Flashe dein Waveshare 4.0" ESP32-S3 Touch Display direkt aus dem Webbrowser. Ohne Entwicklungsumgebung oder lokale Treiber.

1
Display per USB-C verbinden
Schließe das Display über den USB-Port an deinen PC oder Laptop an. Achte darauf, ein vollwertiges Datenkabel zu nutzen (kein reines Ladekabel).
2
Firmware-Version wählen
Wähle eine offizielle Version oder lade eine eigene CamperUI-*-merged.bin Datei hoch.
📥
Hier klicken oder .bin-Datei hineinziehen
Erfordert ein vollständiges *-merged.bin (inkl. Bootloader & Partitionen)
✓ datei.bin (0 MB)
3
Installation starten
Klicke auf den Button, wähle im Browser-Dialog den COM-Port deines Displays aus und bestätige die Installation.
⚠️ Dein Browser unterstützt kein Web Serial!
Bitte öffne diese Seite mit einem modernen Chromium-Browser wie Google Chrome, Microsoft Edge, Brave oder Opera.
⚠️ Sichere Verbindung (HTTPS) erforderlich!
Web Serial steht aus Sicherheitsgründen nur über HTTPS (z. B. auf GitHub Pages) oder localhost zur Verfügung.
Dauer: ca. 30–60 Sekunden. Nach Abschluss startet das Display automatisch neu.
💡 Tipps & Problemlösung
❓ Das Display wird bei der Portauswahl nicht angezeigt?
1. Halte die kleine BOOT-Taste am Display gedrückt.
2. Stecke das USB-Kabel bei gedrückter BOOT-Taste ein (oder drücke kurz RESET, während BOOT gehalten wird).
3. Lass die BOOT-Taste los. Das Display befindet sich nun im sicheren ROM-Bootloader-Modus und wird garantiert erkannt.
❓ Welcher COM-Port ist der richtige?
Im Auswahldialog taucht meist ein Port mit dem Namen "ESP32-S3", "USB JTAG/serial debug unit" oder "CP210x / CH343 USB to UART" auf. Diesen auswählen und auf Verbinden klicken.
❓ Was ist der Unterschied zwischen .bin und -merged.bin?
Für die Erstinbetriebnahme eines neuen Displays wird immer die merged.bin benötigt. Sie enthält Bootloader, Partitionstabelle und Programm ab Speicheradresse 0x0. Die normale .bin ist ausschließlich für Over-the-Air (OTA) Updates im laufenden WLAN-Betrieb gedacht.
