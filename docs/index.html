🚐 CamperUI Flasher • ESP32-S3

Display Erstinbetriebnahme

Flashe dein Waveshare 4.0" ESP32-S3 Touch Display direkt aus dem Webbrowser. Inklusive Vorkonfiguration von WLAN & VanPi vor dem Flash!

1
Display per USB-C verbinden
Schließe das Display über den USB-Port an deinen PC oder Laptop an. Achte auf ein vollwertiges Datenkabel (kein reines Ladekabel).
2
Komplett-Image wählen (*-merged.bin)
Für die Erstinbetriebnahme wird immer das vollständige Image (inkl. Bootloader & Partitionen) geflasht. Drahtlose Updates (OTA) für bestehende Displays erfolgen separat.
ℹ️ Nur Erstinbetriebnahme: Enthält Bootloader (0x0), Partitionstabelle (0x8000) und Applikation ab Adresse 0x0.
📥
Hier klicken oder .bin-Datei hineinziehen
Erfordert ein vollständiges *-merged.bin (inkl. Bootloader & Partitionen)
✓ datei.bin (0 MB)
3
Vorkonfiguration vorab einstellen Optional
Hinterlege deine WLAN- und VanPi-Daten schon jetzt. Das Display verbindet sich nach dem ersten Einschalten sofort vollautomatisch!
► ⚙️ Express-Setup (WLAN, VanPi & Display)
🔒 Datenschutz: Deine Eingaben werden ausschließlich lokal in deinem Browser verarbeitet. Es erfolgt keine Datenübertragung an Server.
4
Installation starten
Klicke auf den Button, wähle im Browser-Dialog den COM-Port deines Displays aus und bestätige das Flashen.
ℹ️ Standard-Installation (unkonfiguriert)
⚠️ Dein Browser unterstützt kein Web Serial!
Bitte öffne diese Seite mit einem modernen Chromium-Browser wie Google Chrome, Microsoft Edge, Brave oder Opera.
⚠️ Sichere Verbindung (HTTPS) erforderlich!
Web Serial steht aus Sicherheitsgründen nur über HTTPS (z. B. auf GitHub Pages) oder localhost zur Verfügung.
Dauer: ca. 30–60 Sekunden. Nach Abschluss startet das Display automatisch neu.
💡 Tipps & Problemlösung
❓ Wie funktioniert die Vorkonfiguration?
Die eingegebenen WLAN- und VanPi-Daten werden unmittelbar vor dem Flashen im Browser direkt an eine reservierte Stelle der Binärdatei geschrieben. Beim allerersten Start liest das Display diese Daten aus und speichert sie automatisch dauerhaft ab. Du musst danach nichts mehr auf dem Touchscreen einstellen!
❓ Das Display wird bei der Portauswahl nicht angezeigt?
1. Halte die kleine BOOT-Taste am Display gedrückt.
2. Stecke das USB-Kabel bei gedrückter BOOT-Taste ein (oder drücke kurz RESET, während BOOT gehalten wird).
3. Lass die BOOT-Taste los. Das Display befindet sich nun im sicheren ROM-Bootloader-Modus und wird garantiert erkannt.
❓ Welcher COM-Port ist der richtige?
Im Auswahldialog taucht meist ein Port mit dem Namen "ESP32-S3", "USB JTAG/serial debug unit" oder "CP210x / CH343 USB to UART" auf. Diesen auswählen und auf Verbinden klicken.
❓ Was ist der Unterschied zwischen .bin und -merged.bin?
Für die Erstinbetriebnahme eines neuen Displays wird immer die merged.bin benötigt. Sie enthält Bootloader, Partitionstabelle und Programm ab Speicheradresse 0x0. Die normale .bin ist ausschließlich für Over-the-Air (OTA) Updates im laufenden WLAN-Betrieb gedacht.
